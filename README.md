# Flight tracker
A small device on a PCB that displays flights in the nearby area.
## Description
A PCB project powered by an ESP32. It uses a ILI9341 screen.
It has 4 navigation buttons for moving around the map, up, down, left and right. 
It also has a rotary encoder by the buttons, so you can zoom in and out. 
The screen is decently large, and it is able to be used as a touchscreen if I want to add some of that functionality later.
